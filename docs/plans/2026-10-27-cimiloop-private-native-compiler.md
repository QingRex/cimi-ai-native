# Native 编译进程的受控写入目录

接续 `f1d30a9`，完整S1五组继续。生产模型已固定用户目录环境，但Native辅助程序的C#编译仍继承宿主用户目录，长路径编译还会把源码投影到全局Temp。本批把实际默认编译路径接到所属构建根，不把环境约束当作完整OS配额证据。

## 实际执行

共享编译入口为每次编译在原构建根下创建独立 `compiler-operations/c-*`：工作目录、HOME／USERPROFILE、AppData、PROGRAMDATA、TEMP／TMP均落在其下。父进程环境不修改，不传登录目录或凭据。私有目录固定物理身份，在启动前及异步返回后核对；环境目录被同路径替换会拒绝。请求原件固定编译器、参数、工作目录、环境映射及物理身份；失败只留无原始错误信息的失败标记，不把候选文件或Windows迟到code0当成功。

沙箱、公开控制器、文件broker、IPC、Job观察器、Codex Job、固定卷读取器，以及时钟和Host1编译入口均复用此路径。源码／编译器摘要与已有构建登记仍由原调用者核对。固定卷读取器的只读打开不编译、不创建私有目录，丢失原可执行文件不重建。

长路径投影只选明确的所属根，拒绝输出逃逸及不同物理设备，不再回退全局Temp；若当前布局不足以满足旧CLR路径能力则拒绝。内部投影原件2记录所属父目录；只删除本次刚创建、身份和条目均完全匹配的投影目录，失败现场保留。原输出路径不缩短或替换。长原目标的低层调用须显式提供其所属短根；旧原件不迁移、不重放编译。

不变更公共Schema242、项目库10或Host1，不处理旧Unknown与旧六个未跟踪文件，不推送。

## 剩余范围

本批尚未覆盖全局文件写入代次辅助器的编译／查询，以及所有Native控制进程的用户目录环境。官方程序系统API的实际写入范围、全部历史容量、网络、真实费用和完整恢复也仍需实现与核验。环境映射与PUBLIC写入测试不能成为完整 `disk_limit` 的supports，也不能替代真实Skill、Human回答、普通Change到ReadyForDelivery、指南实走及最终Matt／Superpowers评审。

后续已把文件写入代次辅助器接到明确项目根，并在不可用时保持字节散列，见[所属根与原件重核](2026-10-27-cimiloop-owned-write-generation.md)。该后续范围不改变本批原验证报告或扩大为完整配额验收。
