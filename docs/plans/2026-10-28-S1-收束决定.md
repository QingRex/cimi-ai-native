# CimiLoop S1 收束决定

日期：2026-10-28。决定人：项目负责人。本文件取代 [Opus 5.5 交接](2026-10-28-CimiLoop-S1-Opus-5.5-交接.md) 中"五组不得缩小"的范围要求；交接中的历史事实与代码现状仍有效。

## 1. 收束后的 S1 定义

在 macOS 本机，用户通过 React 工作台把一个真实普通 Change 走通：

Draft → 澄清 → Contract 确认 → Plan 确认 → Task / WorkItem → 本地模型 Agent 在 git worktree 中修改 → 固定检查 → 证据与独立评价 → ReadyForDelivery。

每一步在页面完成，全部经现有 Kernel 命令；Kernel 仍是唯一业务权威，`command_id` 幂等保持。

## 2. 开发顺位

1. 界面展示与用户直接触达的体验（前端，Claude 负责交付）。
2. 支撑页面主链的必要后端逻辑（Codex `gpt-6.1-sol` / high 负责）。
3. 真实模型验证、真实业务验收放在主链完成之后。

## 3. 保留

- Kernel 命令与查询、Schema 242、项目库格式 10、Host 1 不变。
- 简化 Agent 执行器：本地 OpenAI 兼容 provider（chat completions）+ 工具循环（读 / 列 / 搜 / 写文件、固定检查），每 Task 一个 git worktree，路径限制，AbortController 取消，轮次与 token 硬上限。
- 运行日志以文件保存在项目数据目录（`.git/cimiloop/runs/`），不做 Schema 迁移。
- 服务重启后运行中 Run 进入 Unknown，页面人工核对。
- AI 澄清问题与 AI 评审仅作建议，人做决定。

## 4. 剥离（代码保留，不在主链）

- V1-22 Matt / Superpowers 正式资格与完整独立评审。
- V1-21 Skill 正式资格、权限交集、父子 Skill 家族控制与费用。
- AppContainer、DPAPI、固定卷、物理配额等 Windows 专属隔离。
- 认证逐请求账单结清、币种 / 积分边界、原账户核对。
- 原回执 / SDK / IPC / Native 原字节独立复核链及 Codex 耦合来源。
- 完整崩溃 / 丢响应 / 恢复矩阵。
- S2–S4（批次、发布、环境、紧急修复）与 OpenSpec。

## 5. 工程约束

- 不新增测试；后端不主动扩展边界情况与防御分支。验证方式：`pnpm check`、构建、浏览器实走。
- 仅针对已删除原生前端 `apps/workbench/public/*` 的 DOM 测试随之弃用。
- 已知：`apps/workbench/test/server.test.ts` 在 macOS 上于收束前即因项目身份校验失败，与本次改动无关，暂不处理。
- 真实模型调用暂不进行；业务实现完成后再集中做真实验证。
- 前端：`apps/workbench-web`（Vite + React 19 + TypeScript + Ant Design + TanStack Query + React Router），构建产物输出到 `apps/workbench/dist/web`，由工作台 Node 服务托管，会话 / Origin / CSRF 原样保留。
- 文件归属：Claude 负责 `apps/workbench-web/**` 与文档；Codex 负责 `packages/**`、`apps/workbench/src/**`、`apps/cli/**`。

## 6. 独立验证身份（2026-10-28 决定，同日修订）

Kernel 要求独立评价者不能是实施任务的执行者（`INDEPENDENCE_REQUIRED`）。

最初决定由本地 Agent 身份实施、Human 独立验证。核实后该方案需要修改协议与 Kernel：Agent Run 必须固定带探针证据的正式运行时绑定（`runs.ts`、`providers.ts`），且任务证据与评价只能由绑定的 Human 执行者提交（`verification.ts`）。按本节原约定回到项目负责人，改为：

- 实施记为 Human 运行：当前操作者借助本地模型完成，模型是工具，不冒充独立 Agent 身份；
- 单人模式（项目内只有一个 Human Actor）时，Kernel 允许同一 Human 承担独立验证任务；不新增字段、不改 Schema；
- 页面在验证处明确标注"单人模式 · 非独立验证"，记录如实反映；
- 不登记第二个 Human 身份；
- Agent 作为独立身份执行（含轻量运行时绑定与 Agent 自检证据）留作后续单独工作。

接口契约见 [S1 收束 API 契约](2026-10-28-S1-收束-API契约.md)。
