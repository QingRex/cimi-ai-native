# CimiLoop S1 收束 API 契约

日期：2026-10-28。配套 [S1 收束决定](2026-10-28-S1-收束决定.md)。前端只依赖本文件列出的接口；后端可调整内部实现，但改动接口形状须先更新本文件。

## 0. 通用

- 全部接口沿用工作台现有会话：`POST /api/session {bootstrap}` 换取 Cookie 与 `csrf`；写请求带 `X-CimiLoop-CSRF` 与同源 `Origin`；URL 不允许 query string。
- 失败统一：HTTP 4xx/5xx + `{ ok:false, code, message? }`；Kernel 拒绝原样返回 DomainError（含 `category`、`code`、`details?.diagnostic`）。
- 写入幂等：凡带 `command_id` 的请求，重复提交返回原结果，不重复产生效果。

## 1. 现有接口（保持不变）

| 接口 | 用途 |
|---|---|
| `GET /api/context` | 项目 / 身份 / csrf / 运行时状态（新增字段见 §3.1） |
| `GET /api/dashboard` | 项目、流程、治理（actors / assignments）、执行、provider 目录 |
| `GET /api/decisions` | 全部 Change 及 intent（含待决定请求） |
| `GET /api/changes/:id` | intent、澄清会话、execution、runs、verification |
| `GET /api/objects/:type/:id` | 任意对象详情 |
| `GET/POST /api/changes/:id/clarifications[/:sessionId]` | 计划前 Human 澄清 |
| `POST /api/commands` | Kernel 命令（LocalCommandInput） |
| `GET /api/agent-runs/:runId` | Run 查询 |
| `POST /api/agent-runs/:runId/stop` | 停止，body `{ target:{id:runId}, ... }`（保持现有形状） |

## 2. 新增接口（Codex 实现）

### 2.1 为 Task 启动 Agent 运行

`POST /api/tasks/:taskId/agent-runs`

```json
{ "command_id": "<uuid v7>", "instruction": "可选的补充说明" }
```

服务端一次完成：工作区快照 → PrepareRunContext → ReserveRun → 启动简化执行器。同一 `command_id` 重放返回同一 `run_id`，不重复启动。

```json
{ "ok": true, "run_id": "…", "task_id": "…", "status": "Running" }
```

### 2.2 运行事件流（SSE）

`GET /api/agent-runs/:runId/events` → `text/event-stream`

- 每条事件 `id: <seq>`，`data: <RunEvent JSON>`；断线重连带 `Last-Event-ID`，从下一条继续；运行结束后发送 `done` 并关闭。
- 已结束的 Run 打开时回放全部事件后关闭。

```ts
type RunEvent = { seq: number; at: string } & (
  | { type: "status"; status: "Running" | "Succeeded" | "Failed" | "Cancelled" | "Unknown"; reason?: string }
  | { type: "assistant"; turn: number; text: string }                       // 模型文本输出（整段）
  | { type: "tool_call"; turn: number; call_id: string; tool: string; args: unknown }
  | { type: "tool_result"; call_id: string; ok: boolean; summary: string }  // summary 截断到 4KB
  | { type: "check"; name: string; status: "passed" | "failed"; exit_code: number; duration_ms: number }
  | { type: "usage"; turns: number; prompt_tokens: number; completion_tokens: number; limits: { max_turns: number; max_tokens: number } }
  | { type: "error"; message: string }
  | { type: "done" }
);
```

### 2.3 运行结果

`GET /api/agent-runs/:runId/result`

```json
{
  "ok": true,
  "run_id": "…", "task_id": "…", "status": "Succeeded",
  "started_at": "…", "ended_at": "…",
  "branch": "cimiloop/task-…", "base_commit": "…", "head_commit": "…",
  "summary": "模型最终说明",
  "files": [{ "path": "apps/x.ts", "change": "modified", "additions": 12, "deletions": 3 }],
  "patch": "<git unified diff>",
  "checks": [{ "name": "check", "command": "pnpm check", "status": "passed", "exit_code": 0, "duration_ms": 21000, "output_tail": "…" }],
  "usage": { "turns": 6, "prompt_tokens": 0, "completion_tokens": 0 }
}
```

`patch` 超过 1MB 时截断并带 `"patch_truncated": true`。

### 2.4 AI 建议（仅建议，不写 Kernel）

- `POST /api/changes/:id/ai/clarify` `{}` → `{ ok, questions: [{ question, why }] }`
- `POST /api/agent-runs/:runId/ai/review` `{}` → `{ ok, verdict: "looks_good" | "concerns", summary, findings: [{ file?, line?, severity: "info" | "warn" | "block", message }] }`

模型未配置时返回 `409 { code: "MODEL_NOT_CONFIGURED" }`。

### 2.5 主链表单辅助（按 B0 结论补充）

S1 主链中需要服务端计算的字段（digest、revision、引用）不得要求前端自行计算。以下形状来自 [后端 B0 报告](2026-10-28-S1-收束-后端B0报告.md)；全部带 `command_id`（UUID v7），同 ID 重放返回原结果。

| 接口 | 请求 | 响应 |
|---|---|---|
| `POST /api/tasks/:taskId/evaluations` | `{ command_id, run_id, assessment: { result, observation }, acceptance: [{ key, result, observation }] }` | `{ ok, task_id, source_snapshot_id, evaluation_id, outcome, reasons }` |
| `POST /api/tasks/:taskId/satisfy` | `{ command_id, evaluation_id }` | `{ ok, task_id, status: "Satisfied" }` |
| `POST /api/changes/:changeId/ready-for-delivery` | `{ command_id, run_id, reason, deferred_checks? }` | `{ ok, change_id, evaluation_id, outcome, reasons, status }` |

`result` 取 `supports` / `refutes` / `inconclusive`；`acceptance` 须覆盖该任务全部验收项。`ready-for-delivery` 未 ALLOW 时返回实际 outcome 与 `status: "Executing"`。

## 3. 字段扩展

### 3.1 `GET /api/context` 新增

```json
"runtime": {
  "kind": "lite",
  "provider": { "base_url": "http://127.0.0.1:3425/v1", "model": "codex/gpt-6-luna", "credential_configured": true },
  "limits": { "max_turns": 30, "max_tokens": 200000 },
  "checks": [{ "name": "check", "command": "pnpm check" }]
}
```

未配置时 `runtime.provider` 为 `null`，页面引导配置，不报错。
