本批将已预约的原 SkillInvocation 接入共享应用服务。父 Run 的启动、模型和工具授权继续拒绝未结清的子调用；新增内部子调用执行评估只接受原父范围、原 invocation_ref 和 input_digest，不增加公共 Schema，不升级项目数据库。Kernel 必须核验唯一未结清子调用、完整原身份、当前权限/Binding/预算，以及独立可信宿主对命名方法、Native/SDK/模型/账户/配额/恢复关系的证明。
