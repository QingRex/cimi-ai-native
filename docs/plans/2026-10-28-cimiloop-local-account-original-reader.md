# 本地 provider 原账户接到默认费用入口

本批基于 `cc850b5`，继续完整 S1。共享费用入口现能读取显式本地 provider 安装下的原持久账户，CLI `run costs <run-id>` 和工作台原运行费用查询沿用同一服务。仅按该 Run 的完整原 scope 与原账户 hold 选择来源，不把当前连接作为历史模型身份。

## 行为与原件

新增 `openOriginalDedicatedAccount`，借用现有 Host1／安装原请求和原账户登记。打开前核对原文件存在及物理身份，未登记、丢失或不唯一时不创建账户、不修复数据库。原执行程序丢失、凭据不存在不抹去已预约资金；连接元数据本身须保持安装时的字节与物理身份。

原保管租约继续不暴露执行程序、模型工厂或新请求准入。内部 WeakMap 只允许真实原安装租约读取固定连接元数据。真实账户 owner 在每次读取入口、全部同步账单／保管回调之后和提交之前检查捕获的原来源；调用者替换选项函数不能绕过，异步返回不视为核验。Windows 打开、初始化、显式账单接入均在辅助器 await 前快照选项并核对 guard。

默认费用工厂优先尝试新安装的原账户，只有完整原父 scope 的受保护 hold 匹配才选择。否则关闭借用句柄后核对历史账户；存在新 provider 标记时，历史账户也须有该 scope 的原 hold，不能以空历史账户显示“没有费用”。历史 Codex 已有路由保持。缺少原父 hold／只有原子调用材料时继续 Unknown，不自行补登记或推断零用量。

该只读租约永久拒绝新模型准入。读取 hold、资金快照或关闭句柄不代表已认证账单、费用结清、资源清理或完整生产宿主已安装。没有修改 Schema242／项目库10／Host1，没有发送真实模型请求。
