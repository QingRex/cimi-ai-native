# Codex 原 Run 父子用量接通

接续默认 Runtime／Skill 组合。完整 S1 五组范围保持；本批修复真实子调用会使原父用量查询失败的问题，并把父子原件接到已有费用查询路径，不把 token 当作现金账单。

## 行为

旧 `readCodexAgentRunUsage` 仍严格读取唯一原操作：同一 Run 出现不同 operation_key 时拒绝，不能直接放宽为任意同 Run 记录。新增家族读取器分别核对父操作和每个子操作的原 Codex header、SDK 请求／响应、原容量票据、实际入参及保留用量；同一 Run 的未声明操作、重复范围、错误主体／Runtime 绑定均拒绝。其他项目或 Run 的用量不输出。

`readOriginalLocalCodexRunUsage` 在一个 Kernel Reader 切面枚举全部实际 SkillInvocation，通过原输入摘要、父 RunRecord、真实启动原票据和独立物理出生锚证明关系。子原件从固定 `skill-runtime-originals/<project>/<invocation_key>` 读取，不能由查询请求选择路径或提交子范围清单。受保护原票据封印及最后的原关系复核关闭同次读取。

默认 `productionAgentCosts` 返回借用的原安装 Host 供只读核验，共享 Human 费用服务自动消费；CLI `run costs` 与工作台的原费用查询复用该服务。无子调用保持已有单操作输出格式；有子调用返回 `cimiloop/codex-run-family-usage/1.0.0`。旧可信代码租约不提供原 Host 时维持原严格行为，不能借此声明完整家族。

存在预约却未派发、没有模型 hold 的已预约子调用、原件丢失以及响应未记录均不能伪装为完整用量。缺证子调用不被省略；读取不新增模型、Run、业务观察或容量预约，不返还旧预算。费用读取期间直到异步释放完成后，都会重新核对 Kernel 子调用集合。

所有 Codex 费用仍是 `cost_known:false`、现金／积分为 null；`costs_reconciled`、`run_family_costs_reconciled` 和提供方配额预约均为 false。完成态 PUBLIC 传输用量也不能替代真实提供方账单。此实现不完成 Task，不构成真实 Skill、物理配额或 S1 验收。

## 验证与剩余条件

新增适配器用例首次三个正向失败、两个负向通过；首次负向结果不作为已实现家族读取的证明。实现后独立整文件五项通过，覆盖未知父子预约、缺失子模型 hold、遗漏／外来范围与跨项目数据边界。另在实际 stdio／SDK 原件流程下新增完成态父子读取，完整模型文件 48 项通过；模型、账户与额度回复均为 PUBLIC 夹具，没有读取真实登录凭据。

应用用例在实际 Kernel／SQLite、Git Skill 包、出生锚及 Host 容量实现上先复现缺少家族服务和共享查询丢失用量，两个失败、两个通过。受控方法资格不证明真实方法行为。最终应用、默认 CLI／HTTP 及原账单兼容回归另记，不用局部成功替代整文件结果。

当前 C 盘零可用空间，受影响 AppContainer 完整场景尚未复验通过。D 盘单元临时目录不是专用固定卷；不得将本次满盘中断当成物理配额或异常恢复验收。原失败、Unknown 与历史资源保留。真实完整 Provider／方法原件读取器及默认装载、已准备固定卷、专用官方登录、真实账单来源、Human 原回答和真实 Change 交付仍是后续工作。

Schema 242、项目库 10、Host 1 均未改变，没有自动迁移或 push。

## 最终工程验证

共享费用服务同时核对子调用集合直至异步释放之后；工作台已接受明确的家族用量格式，并显示父／子合计与费用未知。零模型hold的原子调用仍显示待核对，空家族或非法格式不会显示成已核算用量。PUBLIC浏览器回复只验证展示，不作为真实家族原件证明。

追加验证先发现两项夹具问题：连续页面用例误把前一次结果当作新请求完成；异步释放用例试图在未结清的子调用之后再预约，Kernel正确拒绝。页面用例改为等待本次请求及响应完成；集合变更负例使用显式PUBLIC读取视图替换，不绕过Kernel业务门禁或制造新真实调用。最终应用家族整文件5项、浏览器整文件10项全部通过。

与[Runtime／Skill组合](2026-10-24-cimiloop-runtime-skill-admission.md)分阶段合计11个完整文件200项通过，无失败或跳过；模型原件48项、适配器家族5项、共享账单兼容11项包含其中。每个文件只取最终整文件结果，首次失败与中间报告均保留。最终`pnpm check`通过，未运行全仓测试。

默认Windows CLI／HTTP费用整文件首次在Host编译准备阶段失败，输出候选路径长度为260；新建短自有TEMP根复验后通过编译，但在Host目录托管阶段失败，9项仍未执行。没有把它们加入上述200项或宣布默认入口原生回归通过；也没有把改短路径当作C盘满盘、目录托管或完整AppContainer失败的通用修复。两个失败现场保留。完整AppContainer场景、真实固定卷、真实登录与账单、真实Skill和普通Change交付仍未验收。
