# D-252 原执行产物领域依据实施设计

完整五组 S1 继续。本批把 Runtime 原执行产物核验接到 Kernel 保存的原正式约定、计划及任务定义，不代替独立 Task 验收、模型账户、费用或真实 Skill。

当前核验器只对 Runtime 包的少数字段作交叉匹配，不能排除相同 ID 下被替换的领域正文。只新增包内摘要仍由包自身声明；另建外部领域权威违反 Kernel 归属。采用 Kernel 事务内提供不可变 ContractVersion / PlanVersion / TaskDefinitionRecord 的内部只读参数，共享采集准备则通过既有 Kernel 对象查询读取相同固定版本。Runtime 核验全部记录与包完整结构和正文相等、版本 / 项目 / 需求归属、Task / WorkItem 引用与任务定义属于该正式计划。原计划后来变化不重新解释原 Run。

该内部调用扩展不增加公共 Schema、不改变用户库10或原账本格式；缺原领域依据时不能产生结构化产物证明，保留 Unknown。已保存的原观测不重写，同 Command ID 仍重放原 Kernel 收据。原 SDK / Native / 模型字节复核及 false 验收 / 费用边界保持。

先运行同 ID 改正文、外来领域引用和缺少独立原记录的失败反例，再接 Kernel、共享服务及 Runtime 核验路径。验证受影响 Kernel / SQLite / 应用服务 / 原结果与工作台回归；如运行 Windows / AppContainer，记录实际结果与旧崩溃边界，不把跳过计通过。更新实现、研究与交接后仅本地提交。
