# 文件写入代次辅助器的所属根与原件重核

接续 `6222ef0`。上一批已收拢主要Native编译入口，但可选NTFS文件写入代次辅助器仍在全局Temp编译和查询。本批将它接入实际普通模型准入的项目数据根，保留原件物理身份和字节重核要求；完整S1五组继续。

## 实际执行

模型准入在第一次原件切面和后续封口重核中显式传入当前项目数据根。新辅助器只在该根的 `tools/file-write-generation-v2-*` 中选择，同步编译复用上一批的 `compiler-operations/c-*` 私有工作目录与用户目录环境；查询也使用该辅助器自己固定的私有HOME／AppData／PROGRAMDATA／TEMP和cwd。父环境不修改，不传登录目录或凭据，不再选全局Temp。

没有明确所属根的低层调用直接返回不可用，由原件读取者重新散列字节；旧调用方式仍能核验，不用全局工具补证。辅助器不可用、原目录丢失、原二进制丢失、配置侧文件出现、环境或构建原件变化，均不能跳过字节散列或变成ALLOW。新长路径布局超出同步编译器能力时同样回到散列，不把编译投影移到系统盘。

内部辅助器构建2固定原二进制摘要、物理身份、源码摘要及环境目录身份；使用原根下的冻结源码副本编译，并在编译返回后核对编译器和源码。原目录首次以独占创建选出一个构建者，失败或竞争留下的部分目录不修复；重开现存辅助器只读取原目录，不创建缺失目录，不重编译。同字节替换辅助器也会拒绝使用代次；辅助器失效只影响该所属根，不借另一个项目的进程缓存或全局工具。旧全局缓存不读取、不迁移、不清理。Schema242、项目库10、Host1及原Run／费用／Unknown保持。
