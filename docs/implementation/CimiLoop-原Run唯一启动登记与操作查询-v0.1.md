# CimiLoop 原 Run 唯一启动登记与操作查询 v0.1

2026-10-08，D-231，V1-09 续批。承接[原 Task 累计期限与宿主接续](CimiLoop-原Task累计期限与宿主接续-v0.1.md)。本批建立原生 Run / 操作键的唯一启动登记，接通原操作查询、取消请求、原始字节采集与资源恢复。私有 OpenCode 组合仍使用构造模型回复，默认正式 Agent 入口和完整 S1 尚未完成。

## 唯一登记先于外部启动

此前私有组合每次调用都分配新的 UUID 运行目录；同一 Run 的重复调用仍可能启动另一个 Runtime。现在按 Project / Run 原子占用目录，同时独占 Project / 操作键目录，保存不可覆写的原登记与输入。原登记固定完整 Scope、请求摘要、唯一运行目录 ID，以及通过 OS 读取的原宿主 PID / 创建时间 / 程序路径。

请求摘要固定 Runtime 二进制和私有控制器摘要、三个模块的原始字节摘要、固定检查目录、文件 / 检查输入、请求时长和原绝对期限。剩余时间和取消信号不成为新一次启动的理由。同一 Run 再次调用时，只核对原登记：相同输入拒绝重复启动，输入或 Scope 改变拒绝冲突；另一个 Run 不能复用已占用的操作键。

Run / 操作键目录占用和原文件同步完成后才创建 Runtime 控制器。占用后缺原文件、另一宿主正在登记、文件损坏或键冲突都保留原目录，不删除锁后重试。没有重置或自动重新启动接口；缺少原启动资料时不能推断未发生外部效果。

## 原操作控制与事实读取

`LocalAgentRuntimeOperations` 从原 Store 读取 RunRecord / Context / Agent 身份，复用完整原 Scope；异步查询、采集和恢复返回前再次核对。CLI / 工作台 Human 初始化不安装该可信 Agent 组合。

查询复用原启动资源核验器，核对准确原目录、原配置摘要、原控制器文件摘要和完整资源登记，再通过独立身份读取器观察原控制器与原 Runtime 的 PID / 创建时间 / 程序路径。登记中的 phase 或取消文件不能证明进程存活。原进程仍 active 时返回 Preparing / Running；原进程已 absent、原登记已处置且原清理证明完整时返回 Stopped。缺项、无法核对或不一致保留 Unknown / 拒绝；不调用资源恢复，也不改写原记录。

取消接口只同步保存原操作的不可覆写请求，返回 `stopped_proven: false`。执行宿主观察该原文件后，通过 D-229 的原信号关闭原控制器、IPC 和检查宿主。观察到损坏的请求 / 原登记时停止本次调用并保留诊断。原 Task 的绝对期限继续由 D-230 原生控制器独立监督。宿主已丢失时，取消请求不等于已停止，需要观察原身份和资源证明。

采集复制现存的原配置、控制器、资源、原始 stdout / stderr、清理及结果 / 未完成诊断字节，保存有摘要的原始引用并列出缺失文件。运行中的采集可以是部分资料，不能声称所有制品来自同一完成时刻；不会提交 RunObservation。资源恢复定位同一原登记下的原运行目录，仍使用原控制器、原登录环境和原归属核验，不能重开 Runtime 或补写成功。

## 验证和当前边界

合同测试覆盖同 Run 重复启动、改输入 / 操作键、不同 Run 复用原键、部分登记、损坏输入 / 取消，以及缺启动资料时 Unknown 保持。实际 Windows / SDK 测试覆盖原读写完成后的查询和字节采集、独立实际宿主的占用拒绝、准备阶段取消 / 原资源恢复，以及实际 SDK 等待期间的 Running 查询和取消。测试核对原 Task / Run / 用量不因上述外部事实自动推进，临时目录仅在原处置证明核对后清理。

构建与类型检查通过；固定最终 8 个源码文件后，受影响的 7 个测试文件共 33 项全部通过，包含原操作、启动恢复、取消监督、文件 / 检查 SDK 及原 Task 期限回归。编译后的 CLI 帮助入口通过；242 Schema 和四个公共原生控制器保持，8 份修改文档的 300 个本地链接均有效。上述数字仅描述本批验证范围，不是完整 S1 通过率。

首轮查询发现严格 JSON 解析与安全拷贝的对象原型不同，导致原宿主身份被错误拒绝，并使 SDK 回调收到拒绝后继续结束演练；原报告保留。本批统一使用安全拷贝后的纯数据对象进行身份比较，没有放宽 Scope、摘要或原身份校验。实际结果见[D-231 验证记录](../research/CimiLoop-原Run唯一启动登记与操作查询-2026-10-08.json)。

这些事实来自实际 OS、SDK 和原文件；模型回复与受控 Provider / 完整保管链资格仍构造。Stopped 只描述原进程和资源，不能作为 Task 成功、费用结清、真实 Skill 或交付证据。缺原登记的历史操作继续未知。
