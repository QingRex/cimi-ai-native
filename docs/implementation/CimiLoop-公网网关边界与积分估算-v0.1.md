# CimiLoop 公网网关边界与积分估算 v0.1

2026-10-05，V1-09续批，决策D-201。已实现固定智谱Coding Plan域名的公网DNS核验、一次性地址固定与TLS对端核验，并完成实际公网TLS探针。另增加有有效期的GLM-5.3套餐积分估算及计费缺项查询。公网连接探针没有向模型端点发送HTTP请求、读取真实Key或启动Runtime；D-200合成IPC / HTTPS桥接保留，真实模型网关及正式Task / Agent执行尚未验收。领域数据库仍8、宿主TEST账本仍1，未升级用户库。

## 1. 公网连接边界

生产入口固定`open.bigmodel.cn:443`、Coding Plan路径`/api/coding/paas/v4/chat/completions`及目标GLM-5.3，不接收任意URL、域名、代理、信任证书覆盖或凭据。路径是后续HTTP发送的固定目标，本批只建立TLS连接，不能据此声称该HTTP接口或实际模型调用已经通过。

独立Resolver同时查询A / AAAA及TTL。只有明确ENODATA可表示该地址族没有记录；部分查询失败、NXDOMAIN或超时不能用另一个地址族的公开地址掩盖。整个结果最多32条，每条必须是对应地址族、TTL为1–604800秒且为保守判断的公网地址；任一回环、内网、链路本地、共享地址、IPv4映射 / 转换、文档地址或区域标识都会拒绝整个结果。

地址规范化并去重；同一地址采用最低TTL。快照寿命取所有答案的最低TTL与30秒中较小值，从DNS查询开始计时，包含等待两个地址族及结果核验的耗时，答案返回时已过期即拒绝。`resolved_at`记录这个保守寿命起点，UTC仅作历史观测；真正过期判断使用原单调时钟。固定域名、地址集合、所选地址及时间均计入摘要。原集合和每条记录冻结，返回对象由原Boundary的WeakMap登记；复制 / 伪造 / 另一实例的快照不能用于连接，历史JSON也不能成为可执行授权。

TLS直接连接快照中的字面IP，不再次解析DNS、不经HTTP代理、不改连其他地址、不自动重试。SNI及证书域名核对仍使用`open.bigmodel.cn`，保留正常信任链验证和TLS1.2最低版本。完成握手后再核对实际remoteAddress与原所选地址；系统返回的IPv4映射对端只有在底层IPv4完全一致时才允许。证书原始DER摘要作为观测保存，不把动态证书摘要误作永久公钥固定。

快照在连接前及握手后均使用单调时钟检查有效期，DNS与TLS总时限也使用单调时钟；保存的UTC时间仅作历史观测，系统日期回调不能延长存活快照。每份快照仅用于一次拨号。DNS时限结束取消原Resolver，TLS错误 / 中断 / 超时销毁原socket；未经全部核验的socket不交给调用者。这里没有写入HTTP头或请求体；后续实际网关必须在接管核验后的socket时继续落实请求预算、取消和完整响应校验，不能把连接探针当作发送层已经完成。

实现依据固定[Node24.15.0 DNS文档](https://nodejs.org/download/release/v24.15.0/docs/api/dns.html)与[TLS / HTTPS文档](https://nodejs.org/download/release/v24.15.0/docs/api/https.html)，能力结论来自实际代码及验证。仅TLS使用宿主的正常信任根；没有修改系统信任库或增加AppContainer网络Capability。

## 2. 积分估算与真实计费准入

2026-10-05读取的[官方Coding Plan说明](https://docs.bigmodel.cn/cn/coding-plan/overview)区分套餐积分、工具适用环境和额度刷新。GLM-5.3输入 / 缓存输入 / 输出的公开抵扣系数为6.9 / 1.7 / 24，按每万Token换算积分；本批估算对全部输入使用较高输入系数、不采用缓存或非高峰活动折扣，并向上取整至整积分。积分使用独立单位`ZHIPU_CODING_PLAN_CREDIT`，不冒充CNY、USD或既有TEST金额。

`estimateCodingPlanCredits`只接受输入与输出Token数量；使用整数BigInt计算，并记录固定模型和费率观察摘要。公开费率观察在2026-10-12T00:00:00Z到期，到期后拒绝新估算，不能无限沿用动态网页事实。输入最多1048576、输出最多131072是估算函数的接受范围，不代表它已证明实际请求的Token上界。思考输出必须纳入另行验证的总输出上界；函数没有把请求字节数当真实Token数，也不会根据可见回答长度推断思考费用。

估算结果固定`token_bounds_verified=false`、`account_version_verified=false`、`admission_ready=false`和`actual_cost_known=false`。官方GLM-5.3说明显示模型会启用思考，详见[模型文档](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)；仍需核验实际接口的完整生成约束和计费语义。公开套餐说明不能证明当前专用Key属于新版个人积分套餐，也不能自动证明自定义网关符合工具环境要求。

`assessDedicatedGatewayBilling`验证专用连接的公共配置后，只返回NEED_MORE_EVIDENCE及具体缺项。`requireDedicatedGatewayBilling`仍在凭据解密、账本创建、DNS或模型请求前拒绝。不会把未知旧套餐自动改为新版，不会把订阅额度记为零美元，也不会切换到普通按量API或消耗人类OpenCode登录。

下一批需要确认当前专用连接的套餐版本和网关适用环境，证明输入及包含思考的输出上界，固定实际配额 / 计费策略与授权预算，建立独立持久积分预留及账单核对，再验收携带凭据的HTTPS与无网络Runtime桥接。积分配额与Task现金预算的关系须显式建模，不能只把原TEST币种换成积分来提升受控执行。

## 3. CLI与机器格式

```powershell
pnpm cimiloop --json runtime gateway-network-probe `
  --output-dir '<公网连接观测目录>' --max-elapsed-ms 8000
```

时限为DNS与TLS合计1000–30000毫秒，默认8000。命令固定目标，不接受连接、Key、URL、代理或Runtime二进制。每次独立保存`runs/<UUID>/`与内容寻址原始观测，顶层保存最新结果；原观察仍保留。公网连接通过退出0，连接未通过退出1，参数错误退出2；退出0只代表这一项DNS / TLS探针通过。

新增独立严格v2 Schema `RuntimeGatewayNetworkProbeResult`，scope=`public_gateway_network_probe`。记录固定路由规则摘要、DNS快照 / 选择 / 有效期 / 摘要及TLS实际对端 / 协议 / 证书摘要。HTTP请求、真实Key读取和外部模型请求固定0，Runtime启动和正式执行固定false；billing准入与cost_known固定false。解析器核对地址集合、快照寿命、选择 / 对端、摘要和通过状态，拒绝损坏或夸大证明。

费率摘要仅是有日期的来源证明，旧网络观测不因后来更新公开费率而不可读取；它也不能授予计费准入。原RuntimeOperationResult / RuntimeProbeResult、D-198–200格式及冻结v1保持。本格式不能当作真实模型契约结果导入Provider批准；D-197的真实Runtime host_allowlist / required_cap继续拒绝，等待完整真实网关及费用验收。
